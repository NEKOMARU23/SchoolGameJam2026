## 1. ゲームの概要

- **ジャンル**: 取り調べ推理アドベンチャー
- **目的**: 4人の容疑者の中に紛れた **「人格AI」を見つけ出す**
- **期間**: **7日間**。1〜6日目は取り調べ、**最終日（7日目）は全員を「AI確定」か「解放」で判定**する
- **AI は途中で決まる**: ゲーム開始時は全員人間。会話の内容や、決まった日までにフラグを集めたかで、だれかが AI になる（0人のことも、複数人のこともある）。だれが AI になったかはプレイヤーには見えない

## 2. 画面の流れ

```
Title（タイトル）
  ├─ スタート（はじめから） → InGame（本編）
  │     └─ 7日目に全員を判定 → リザルト → エンディングの会話
  │           ├─ エンディングの種類が「クリア」       → ClearScene
  │           └─ エンディングの種類が「ゲームオーバー」→ GameOverScene
  │                 └─ どちらも「このセーブを消しますか？」→ Title に戻る
  ├─ つづきから（セーブ枠を選んで、その続きから InGame へ）
  ├─ オプション（音量・画面表示・文字の速さ・オート・スキップ）
  └─ エンディング一覧（見たエンディングを見返す）
```

- 起動時に **Manager シーン**（BGM・効果音・オプション）が自動で追加読み込みされます。
- Result シーンはビルド設定で無効になっていて、現在は使っていません（リザルトは InGame の中の画面で表示）。

### InGame の中の画面

| 画面 | 内容 |
|---|---|
| モニター画面 | 4つの部屋（A〜D）を選ぶ。モニターには各部屋のキャラの顔と名前プレートが映る。左上に「1日を終える」「今日をリセット」「ログ」「設定」のボタン（文字つき）。机の上に資料（ノート）と**スマホ**（マウスを乗せると持ち上がって名前が出る） |
| 取調室 | 選んだ容疑者にアクションを行う。セリフは画面下の会話枠に表示。行動を選ぶと行動のボタンは消え、その日にもう取り調べた人の部屋に入り直すと「今日はもう取り調べました」と出る |
| プロフィール（資料） | ポイントで容疑者の基礎情報・過去情報を解禁して読む |
| 聞き取りパネル | 「聞き取り」で、だれについて聞くかを選ぶ |
| 選択肢 | 会話の後に、条件を満たした選択肢を出す（選ぶまで先に進めない） |
| 確認ダイアログ | AI確定・解放・プロフィール解禁・リセット・1日終了の前に確認する |
| ログ | これまでのセリフを読み返す |
| リザルト | 1日の終わりに、その日の取り調べ内容と獲得ポイントを表示 |
| スマホ会話画面 | 補助ちゃんと話す。朝の会話がある日は、日の始めに自動で開く |
| ロード画面 | 日付が変わるときに「N日目 / Now Loading...」を表示 |
| エンディング | 最終日の後、エンディングの会話を画面全体で見せる |
| オプション | 音量などの設定。ゲーム中は「セーブ」「ロード」ボタンも出る |
| セーブ枠 | 20枠。何日目・残り行動回数・保存した日時を表示。上書き・削除・ゲーム中のロードは確認してから |

## 3. ゲームのルール

### 1日の流れ（1〜6日目）
1. モニター画面で部屋を選び、取調室でアクションを行う
2. **1日に行動できるのは4回まで**。**同じ人には1日1回まで**
3. 「1日終了」ボタン → 確認 → リザルト画面 → 「次の日へ」で翌日（ロード画面が入る）
4. 翌日になるときに、AI判定シートの判定が行われる（下の「AI になる仕組み」参照）

### 取調室のアクション

| アクション | 出せる日 | 効果 |
|---|---|---|
| 拷問 / 対話 / 交渉 | 1〜6日目 | ポイントは**三段階**（Excel の日別設定で決まる）。**成功**＝その日の「正解行動」: ポイント（仮で20）＋好感度+1。**普通**＝正解でも NG でもない行動: ポイント（仮で10）。**最低**＝その日の「NG行動」: ポイント（仮で0）＋好感度-1。**ポイントは減らない** |
| 聞き取り | 1〜6日目 | 他の人について話を聞く。**正解判定なしで +10ポイント** |
| 解放 | **最終日だけ** | その人を「AI ではない」と判定する。行動1回を使う |
| AI確定 | **最終日だけ** | その人を「AI だ」と判定する。行動1回を使う |

- ポイントの値は InGame.prefab の InterrogationManager で変えられます（今は仮で 成功20・普通10・最低0。あとで調整する）。
- 行動の会話が終わったら、入ったポイントが「+20pt」のように1.5秒ほど出ます（0のときは出ません）。好感度は画面に出しません。
- 最終日は拷問・対話・交渉・聞き取りのボタンが消え、解放・AI確定だけが出ます。
- 最終日のモニターには、まだ判定していない部屋に「未判定」、判定した部屋に「AI判定」（赤）か「解放」（白）が出ます。
- 判定した人の部屋には入れません（やり直すときは「今日をやり直す」）。

### 最終日の判定と勝ち負け
- **全員を判定するまで「1日終了」できない**（押すと「まだ判定していない人がいます」と出る）
- AI が複数いれば全員を AI確定、AI がいなければ全員を解放すると「全員正解」
- **AI を1人でも解放したら**「AIを解放した」
- **人間を AI確定したら**「人間をAI確定した」（それだけではゲームオーバーにならない）
- この判定結果とフラグで、Excel のエンディングシートからエンディングが決まり、エンディングの「種類」でクリア画面かゲームオーバー画面に移る

### AI になる仕組み
- **会話で AI になる**: 条件シートの「AI化」列に書いたキャラは、その会話を聞いた瞬間に AI になる
- **決まった日までに進展がないと AI になる**: AI判定シートの「判定日」の終わりに、「回避フラグ」がそろっていなければ AI になる
- 一度 AI になったら元には戻らない（ただし「今日をやり直す」で、その日に AI になった分は戻る）

### セリフの出し分け
Excel の **条件シート** で、「何日目に・だれに・どの行動をしたとき」に出す会話を、優先度の小さい順に調べます。書いた条件をすべて満たした最初の行の会話が出ます。

| 条件の列 | 内容 |
|---|---|
| 本人の好感度 | 会話の相手の好感度が指定値以上 |
| 他キャラの好感度 | 例: `B>=2` |
| 行動回数 | このキャラにこの行動をした通算回数が指定値以上 |
| 必要フラグ / NGフラグ | 指定したフラグがすべて ON / 1つでも ON なら出さない |

会話を聞くと、「獲得フラグ」が ON になり、「AI化」のキャラが AI になります。

### 会話の選択肢
- 会話の後に、**選択肢シート** に書いた選択肢のうち、条件を満たすものだけが出ます（取調室・スマホ両方）
- 選ぶと好感度の変化・獲得フラグ・AI化が反映され、次の会話に続きます。次の会話にも選択肢があれば続けて選べます
- 選択肢を選んでも、行動回数・スマホの回数は増えません

### フラグ
キーアイテム（`item_`）・情報（`info_`）・進行フラグ（`flag_`）を ON / OFF で記録します。会話の出し分け、選択肢、AI判定、エンディングの条件に使います。

### プロフィール（資料）の解禁
- ポイントを消費して解禁します（確認ダイアログが出ます）。解禁状態はキャラごとに別です。
- 基礎情報: ココア 20pt、それ以外 30pt
- 過去情報: 50pt / 70pt / 30pt（`PAST_1` 〜 `PAST_3`）
- **画面の置き場所の都合で、過去情報は3番目の枠（PAST_3）だけ表示**しています（意図した仕様）。資料画面を作り直したら、全部表示する予定です（`Docs/資料画面の動き_プログラム側.md`）。

### 今日をやり直す（リセット）
その日の朝の状態に戻します。戻るもの: ポイント、行動回数、取り調べ済みの記録、好感度、プロフィールの解禁、解放・AI確定、AI になったキャラ、フラグ、アクションの通算回数、スマホの会話回数。

### スマホ（補助ちゃんとの会話）
- モニター画面のスマホを押すと補助ちゃんの会話画面が開きます。
- **1日に聞ける回数 ＝ 条件シートに書いたその日の「回目」の最大**。使い切った後に押すと「**今日はもう連絡ができない**」と表示されます。
- **朝の会話**: 条件シートに行動「朝」の行がある日は、日が変わる演出のあと、スマホの会話画面が自動で開きます（呼び出し音は素材ができたら鳴らす）。会話が終わると、日が変わるときと同じ演出でモニター画面に戻ります。スマホで話せる回数は減りません。「今日をやり直す」やロードでは流れません（会話で手に入るフラグはそのまま残ります）。今は7日目（最終日の説明）だけ
- 翌日・リセットで回数は戻ります。

### 各日の正解行動（ネタバレ注意）

| 日 | A ココア | B メリ | C カネル | D レイジ |
|---|---|---|---|---|
| 1 | 対話 | 対話 | 対話 | 交渉 |
| 2 | 対話 | 対話 | 対話 | 対話 |
| 3〜7 | 拷問 | 対話 | 対話 | 対話 |

（Excel の「日別設定」シートで変えられます。最終日は取り調べできないので、7日目の設定は今は使われません）

### エンディング一覧
- 見たエンディングは、セーブとは別のファイル（`ending_record.json`）に記録されます。

### 手に入れた情報の記録（資料画面用）
- 情報・キーアイテムを手に入れると、何日目に、どうやって手に入れたか（例: ココアに対話）が記録されます。今日をやり直すと消え、セーブ・ロードで戻ります。
- 一度でも手に入れた情報は、セーブとは別のファイル（`info_record.json`）にも残り、2周目以降も資料画面で読めます（画面はデザイナーさん待ち）。ただし、会話の出し分けなどのフラグは、その周回で手に入れたものだけです。
- 周回は、エンディングまで行くと増えます。
- ポイントで解禁する情報（フラグ一覧の「解禁ポイント」がある情報）は、ポイントを使って手に入れます。
- タイトル画面の「エンディング一覧」で、見たものは名前が出てもう一度再生でき、見ていないものは「？？？」と表示されます。

### オプション
- タイトル画面とゲーム中の設定ボタンから開けます（Esc キーでも開閉。ログや確認の窓が開いているときは、Esc で先にそれが閉じる）。
- 設定できるもの: BGM・SE の音量、画面表示（フルスクリーン／ウィンドウ）、文字の速さ（3段階）、オートの待ち時間（3段階）、スキップの種類（既読のみ／すべて）。`settings.json` に保存されます。

### セーブ・ロード
- **手動セーブだけ**（自動セーブはしない）。ゲーム中のオプション画面の「セーブ」から、20枠のどれかに保存します。
- 今の状態に加えて、**その日の朝の状態とログも保存**します（ロードした後でも「今日をやり直す」が使える）。
- 会話の途中・選択肢を選んでいる途中などはセーブできません。
- ロードは、タイトルの「つづきから」と、ゲーム中のオプション画面の「ロード」からできます。
- クリア・ゲームオーバーになったら、そのゲームのセーブを消すかどうかを選べます。
- 保存先: `saves/slot_01.json`〜`slot_20.json`（`Application.persistentDataPath` の中）

### キーボード操作
| キー | 操作 |
|---|---|
| Enter / Space | 会話を進める（文字送りの途中なら全文を出す）。取調室・スマホ・エンディングの会話 |
| Ctrl（押している間） | スキップ |
| A | オートの切り替え |
| L | ログを開く・閉じる |
| Esc | ログ・確認の窓を閉じる。開いていなければオプションの開閉 |
| F1 | デバッグメニュー（開発中のみ） |

- オプション・セーブ画面・確認の窓・選択肢・デバッグメニューが開いている間と、日が変わる演出の間は効かない

### オート・スキップ
- 取調室とスマホの会話枠の「オート」「スキップ」ボタンで切り替えます（どちらで押しても共通）。
- **オート**: ページを表示し終えたら、オプションの待ち時間のあとに次のページへ進みます。
- **スキップ**: 会話をどんどん送ります。オプションが「既読のみ」なら一度読んだ会話だけを飛ばし、未読の会話に来たら止まります。選択肢が出たときも止まります。
- 一度最後まで読んだ会話は `read_record.json` に記録されます（セーブとは別で、全セーブ共通）。

## 4. データの編集方法

### シナリオは Excel で書く
**`Assets/Editor/ScenarioData.xlsx`** にまとめて書き、Unity のメニュー **「Tools ＞ シナリオExcelを取り込む」** でゲームに反映します。書き間違い（存在しないフラグ名・セリフID、優先度の抜けなど）があれば一覧で表示され、取り込まれません。

| シート | 書くこと |
|---|---|
| 説明 | 書き方の説明と例 |
| 本文 | 会話の中身。1行 = 1ページ。同じセリフIDの行が1つの会話になる。話者・SE・立ち絵（・背景・イベント絵・エフェクト・BGM）も指定できる |
| 条件 | 何日目に、だれに、どの行動をしたとき、どの会話を出すか。スマホの会話もここ（行動「スマホ」と「回目」）。日の始めに自動で流れる会話は行動「朝」 |
| 選択肢 | 会話の後に出す選択肢 |
| 日別設定 | 各日の、各キャラへの正解行動・NG行動 |
| フラグ一覧 | 使うフラグの一覧（ここにない名前を書くとエラー）。資料画面用に、見出し・解禁ポイント（空なら会話で手に入る）・関係するキャラ・画像（`Data/Item`）の列もある |
| AI判定 | 決まった日までに条件を達成していないと AI になる判定 |
| エンディング | 最終日の判定とフラグで、どのエンディングになるか |
| リスト | プルダウンの選択肢 |

- 1列目が `#` で始まる行は取り込まれません（下書き・コメントに使う）。
- 立ち絵・SE などの素材は、`Assets/TechC/SchoolGameJam2026/Data/` の `Character`・`SE`・`BGM`・`Background`・`EventCG`・`Effect` フォルダに置き、Excel にはファイル名（拡張子なし）を書きます。
- 取り込んだ結果は `Data/ScenarioDatabase.asset` に保存されます（手で編集しない）。

### その他のデータ

| 何を | どこで |
|---|---|
| 容疑者のプロフィール | `Data/*_ProfileData.asset`（過去情報の「解禁の確認で表示する名前」もここ） |
| ポイント・行動回数などの数値 | `InGame.prefab` の GameManager（InterrogationManager）。※シーン側で上書きされている値もある |
| ロード画面の時間・見た目 | `Canvas/DayTransitionPanel`（DayTransitionUI） |
| お知らせの表示時間 | MonitorPanel の MonitorUI → Notice Duration |
| エンディングの再生画面の見た目 | `Prefab/EndingPlayer.prefab` |

## 5. 開発用の機能

### デバッグメニュー（F1）
Unity エディターと開発用ビルドでだけ、**F1 キー** で開けます（本番のビルドには入りません）。
- 日付の移動、今日の朝に戻す
- ポイントの増減、今日の行動回数・スマホの会話回数を 0 に戻す
- 各キャラの好感度の増減、AI の ON / OFF
- フラグの ON / OFF

### 自動テスト
`Assets/TechC/SchoolGameJam2026/Script/Test/` に PlayMode テストがあります（**122本、すべて成功**）。

- **実行方法**: Unity の `Window > General > Test Runner` → PlayMode タブ → **Run All**
- 主な内容: 画面のボタン操作、7日間の通しプレイ、最終日の判定とクリア／ゲームオーバー、AI判定シート、確認ダイアログ、Excel の取り込みチェック、会話の出し分け、選択肢、スマホ会話、エンディングと一覧、オプションの保存、今日をやり直す、セーブ・ロード、オート・スキップ
- ゲームのルールを変えたら、テストが失敗しないか確認してください。
- テストのあいだ、見たエンディング・既読の記録・セーブは、本物のファイルではなくテスト用の場所に書きます。

### Unity CLI（コマンドで Unity を操作する道具）
Unity 公式のコマンドラインツールです。PowerShell で `winget install Unity.CLI` を実行すると入ります。
プロジェクトには、開いている Unity を外から操作するための **Pipeline パッケージ**（`com.unity.pipeline`）が入っています。
- `unity status` … 開いている Unity とつながっているか（「ready」ならつながっている）
- `unity recompile` … 開いている Unity でコンパイルして、エラーがないか調べる
- `unity command run_tests --mode PlayMode --async_tests true` → `unity command test_status` … Unity を開いたまま自動テストを実行する
- `unity command capture_game_view --save_path <場所>` … Game ビューのスクリーンショットを撮る

Claude Code（AI）は、これを使って Unity を閉じてもらわずにテストや画面の確認をしています。

## 8. 作業するときの注意
- **絵を AI に読み込ませない**（デザイナーさんの指示。2026-10-18）。AI（Claude Code）は、立ち絵・ボタンなどの画像ファイルや、絵が写るゲーム画面のスクリーンショットを開かない。絵を新しく作ることもしない。見た目の確認は人が Unity で行う。前に AI が作った画像（スクリーンショット・イメージ画像・光と横線の画像）は 2026-10-19 に消し、資料の図は四角と文字だけの図（`Docs/tools/make_wireframes.py`）に作り直した
- **Unity を開いたまま、外部ツールで prefab やシーンのファイルを書き換えない**。古い状態が混ざって表示がおかしくなることがある（起きたら Unity を開き直す）。Unity の中で書き換える（エディタースクリプト・Unity CLI）なら大丈夫。
- VFX Graph は `vfx-test` ブランチにだけ入っている。ブランチを行き来したあとエフェクトが出なくなったら、`.vfx` ファイルを右クリック →「Reimport」。
- **Excel を書き換えたら、必ず「Tools ＞ シナリオExcelを取り込む」を押す**（押さないとゲームに反映されない）。
- `ProjectSettings.asset` などが「変更あり」になっていても、改行コードの違いだけのことがある。
- 1つの機能ごとにブランチ（`feature/名前/機能名`）を作り、main にはプルリクエストで入れる。
- コミットメッセージは `fix:` `feat:` `refactoring:` `chore:` `test:` の接頭語＋日本語で内容を書く。
