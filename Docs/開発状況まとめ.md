## 1. ゲームの概要

- **ジャンル**: 取り調べ推理アドベンチャー
- **目的**: 4人の容疑者の中に紛れた **「人格AI」を見つけ出す**
- **期間**: **7日間**。1〜6日目は取り調べ、**最終日（7日目）は全員を「AI確定」か「解放」で判定**する
- **AI は途中で決まる**: ゲーム開始時は全員人間。会話の内容や、決まった日までにフラグを集めたかで、だれかが AI になる（0人のことも、複数人のこともある）。だれが AI になったかはプレイヤーには見えない

## 2. 画面の流れ

```
Title（タイトル）
  ├─ スタート → InGame（本編）
  │     └─ 7日目に全員を判定 → リザルト → エンディングの会話
  │           ├─ エンディングの種類が「クリア」       → ClearScene
  │           └─ エンディングの種類が「ゲームオーバー」→ GameOverScene
  │                 └─ どちらも → Title に戻る
  ├─ オプション（音量・文字の速さ）
  └─ エンディング一覧（見たエンディングを見返す）
```

- 起動時に **Manager シーン**（BGM・効果音・オプション）が自動で追加読み込みされます。
- Result シーンはビルド設定で無効になっていて、現在は使っていません（リザルトは InGame の中の画面で表示）。

### InGame の中の画面

| 画面 | 内容 |
|---|---|
| モニター画面 | 4つの部屋（A〜D）を選ぶ。プロフィール・リセット・1日終了・ログ・**スマホ**・設定のボタンがある |
| 取調室 | 選んだ容疑者にアクションを行う。セリフは画面下の会話枠に表示 |
| プロフィール（資料） | ポイントで容疑者の基礎情報・過去情報を解禁して読む |
| 聞き取りパネル | 「聞き取り」で、だれについて聞くかを選ぶ |
| 選択肢 | 会話の後に、条件を満たした選択肢を出す（選ぶまで先に進めない） |
| 確認ダイアログ | AI確定・解放・プロフィール解禁・リセット・1日終了の前に確認する |
| ログ | これまでのセリフを読み返す |
| リザルト | 1日の終わりに、その日の取り調べ内容と獲得ポイントを表示 |
| スマホ会話画面 | 補助ちゃんと話す |
| ロード画面 | 日付が変わるときに「N日目 / Now Loading...」を表示 |
| エンディング | 最終日の後、エンディングの会話を画面全体で見せる |

## 3. ゲームのルール

### 1日の流れ（1〜6日目）
1. モニター画面で部屋を選び、取調室でアクションを行う
2. **1日に行動できるのは4回まで**。**同じ人には1日1回まで**
3. 「1日終了」ボタン → 確認 → リザルト画面 → 「次の日へ」で翌日（ロード画面が入る）
4. 翌日になるときに、AI判定シートの判定が行われる（下の「AI になる仕組み」参照）

### 取調室のアクション

| アクション | 出せる日 | 効果 |
|---|---|---|
| 拷問 / 対話 / 交渉 | 1〜6日目 | その日の「正解行動」（Excel の日別設定）を選ぶと **ポイント獲得＋好感度+1**。外れると **ポイント-5**（0未満にはならない）。その日の「NG行動」だった場合は **好感度-1** |
| 聞き取り | 1〜6日目 | 他の人について話を聞く。**正解判定なしで +10ポイント** |
| 解放 | **最終日だけ** | その人を「AI ではない」と判定する。行動1回を使う |
| AI確定 | **最終日だけ** | その人を「AI だ」と判定する。行動1回を使う |

- 正解時のポイントは現在 **200**（シーン側の設定値。prefab 側は 2000000 になっているので、意図した値か要確認）。
- 最終日は拷問・対話・交渉・聞き取りのボタンが消え、解放・AI確定だけが出ます。
- 判定した人の部屋には入れません（やり直すときは「今日をやり直す」）。

### 最終日の判定と勝ち負け
- **全員を判定するまで「1日終了」できない**（押すと「まだ判定していない人がいます」と出る）
- AI が複数いれば全員を AI確定、AI がいなければ全員を解放すると「全員正解」
- **AI を1人でも解放したら**「AIを解放した」
- **人間を AI確定したら**「人間をAI確定した」（それだけではゲームオーバーにならない）
- この判定結果とフラグで、Excel のエンディングシートからエンディングが決まり、エンディングの「種類」でクリア画面かゲームオーバー画面に移る

### AI になる仕組み
- **会話で AI になる**: 条件シートの「AI化」列に書いたキャラは、その会話を聞いた瞬間に AI になる
- **決まった日までに進展がないと AI になる**: AI判定シートの「判定日」の終わりに、「回避フラグ」がそろっていなければ AI になる
- 一度 AI になったら元には戻らない（ただし「今日をやり直す」で、その日に AI になった分は戻る）

### セリフの出し分け
Excel の **条件シート** で、「何日目に・だれに・どの行動をしたとき」に出す会話を、優先度の小さい順に調べます。書いた条件をすべて満たした最初の行の会話が出ます。

| 条件の列 | 内容 |
|---|---|
| 本人の好感度 | 会話の相手の好感度が指定値以上 |
| 他キャラの好感度 | 例: `B>=2` |
| 行動回数 | このキャラにこの行動をした通算回数が指定値以上 |
| 必要フラグ / NGフラグ | 指定したフラグがすべて ON / 1つでも ON なら出さない |

会話を聞くと、「獲得フラグ」が ON になり、「AI化」のキャラが AI になります。

### 会話の選択肢
- 会話の後に、**選択肢シート** に書いた選択肢のうち、条件を満たすものだけが出ます（取調室・スマホ両方）
- 選ぶと好感度の変化・獲得フラグ・AI化が反映され、次の会話に続きます。次の会話にも選択肢があれば続けて選べます
- 選択肢を選んでも、行動回数・スマホの回数は増えません

### フラグ
キーアイテム（`item_`）・情報（`info_`）・進行フラグ（`flag_`）を ON / OFF で記録します。会話の出し分け、選択肢、AI判定、エンディングの条件に使います。

### プロフィール（資料）の解禁
- ポイントを消費して解禁します（確認ダイアログが出ます）。解禁状態はキャラごとに別です。
- 基礎情報: ココア 20pt、それ以外 30pt
- 過去情報: 50pt / 70pt / 30pt（`PAST_1` 〜 `PAST_3`）
- **画面の置き場所の都合で、過去情報は3番目の枠（PAST_3）だけ表示**しています（意図した仕様）。

### 今日をやり直す（リセット）
その日の朝の状態に戻します。戻るもの: ポイント、行動回数、取り調べ済みの記録、好感度、プロフィールの解禁、解放・AI確定、AI になったキャラ、フラグ、アクションの通算回数、スマホの会話回数。

### スマホ（補助ちゃんとの会話）
- モニター画面のスマホを押すと補助ちゃんの会話画面が開きます。
- **1日に聞ける回数 ＝ 条件シートに書いたその日の「回目」の最大**。使い切った後に押すと「**今日はもう連絡ができない**」と表示されます。
- 翌日・リセットで回数は戻ります。

### 各日の正解行動（ネタバレ注意）

| 日 | A ココア | B メリ | C カネル | D レイジ |
|---|---|---|---|---|
| 1 | 対話 | 対話 | 対話 | 交渉 |
| 2 | 対話 | 対話 | 対話 | 対話 |
| 3〜7 | 拷問 | 対話 | 対話 | 対話 |

（Excel の「日別設定」シートで変えられます。最終日は取り調べできないので、7日目の設定は今は使われません）

### エンディング一覧
- 見たエンディングは、セーブとは別のファイル（`ending_record.json`）に記録されます。
- タイトル画面の「エンディング一覧」で、見たものは名前が出てもう一度再生でき、見ていないものは「？？？」と表示されます。

### オプション
- タイトル画面とゲーム中の設定ボタンから開けます。BGM・SE の音量と文字の速さを変えられ、`settings.json` に保存されます。

## 4. データの編集方法

### シナリオは Excel で書く
**`Assets/Editor/ScenarioData.xlsx`** にまとめて書き、Unity のメニュー **「Tools ＞ シナリオExcelを取り込む」** でゲームに反映します。書き間違い（存在しないフラグ名・セリフID、優先度の抜けなど）があれば一覧で表示され、取り込まれません。

| シート | 書くこと |
|---|---|
| 説明 | 書き方の説明と例 |
| 本文 | 会話の中身。1行 = 1ページ。同じセリフIDの行が1つの会話になる。話者・SE・立ち絵（・背景・イベント絵・エフェクト・BGM）も指定できる |
| 条件 | 何日目に、だれに、どの行動をしたとき、どの会話を出すか。スマホの会話もここ（行動「スマホ」と「回目」） |
| 選択肢 | 会話の後に出す選択肢 |
| 日別設定 | 各日の、各キャラへの正解行動・NG行動 |
| フラグ一覧 | 使うフラグの一覧（ここにない名前を書くとエラー） |
| AI判定 | 決まった日までに条件を達成していないと AI になる判定 |
| エンディング | 最終日の判定とフラグで、どのエンディングになるか |
| リスト | プルダウンの選択肢 |

- 1列目が `#` で始まる行は取り込まれません（下書き・コメントに使う）。
- 立ち絵・SE などの素材は、`Assets/TechC/SchoolGameJam2026/Data/` の `Character`・`SE`・`BGM`・`Background`・`EventCG`・`Effect` フォルダに置き、Excel にはファイル名（拡張子なし）を書きます。
- 取り込んだ結果は `Data/ScenarioDatabase.asset` に保存されます（手で編集しない）。

### その他のデータ

| 何を | どこで |
|---|---|
| 容疑者のプロフィール | `Data/*_ProfileData.asset`（過去情報の「解禁の確認で表示する名前」もここ） |
| ポイント・行動回数などの数値 | `InGame.prefab` の GameManager（InterrogationManager）。※シーン側で上書きされている値もある |
| ロード画面の時間・見た目 | `Canvas/DayTransitionPanel`（DayTransitionUI） |
| お知らせの表示時間 | MonitorPanel の MonitorUI → Notice Duration |
| エンディングの再生画面の見た目 | `Prefab/EndingPlayer.prefab` |

## 5. 開発用の機能

### デバッグメニュー（F1）
Unity エディターと開発用ビルドでだけ、**F1 キー** で開けます（本番のビルドには入りません）。
- 日付の移動、今日の朝に戻す
- ポイントの増減、今日の行動回数・スマホの会話回数を 0 に戻す
- 各キャラの好感度の増減、AI の ON / OFF
- フラグの ON / OFF

### 自動テスト
`Assets/TechC/SchoolGameJam2026/Script/Test/` に PlayMode テストがあります（**75本、すべて成功**）。

- **実行方法**: Unity の `Window > General > Test Runner` → PlayMode タブ → **Run All**
- 主な内容: 画面のボタン操作、7日間の通しプレイ、最終日の判定とクリア／ゲームオーバー、AI判定シート、確認ダイアログ、Excel の取り込みチェック、会話の出し分け、選択肢、スマホ会話、エンディングと一覧、オプションの保存、今日をやり直す
- ゲームのルールを変えたら、テストが失敗しないか確認してください。

## 8. 作業するときの注意
- **Unity を開いたまま、外部ツールで prefab やシーンのファイルを書き換えない**。古い状態が混ざって表示がおかしくなることがある（起きたら Unity を開き直す）。
- **Excel を書き換えたら、必ず「Tools ＞ シナリオExcelを取り込む」を押す**（押さないとゲームに反映されない）。
- `ProjectSettings.asset` などが「変更あり」になっていても、改行コードの違いだけのことがある。
- 1つの機能ごとにブランチ（`feature/名前/機能名`）を作り、main にはプルリクエストで入れる。
- コミットメッセージは `fix:` `feat:` `refactoring:` `chore:` `test:` の接頭語＋日本語で内容を書く。
