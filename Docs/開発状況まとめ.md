## 1. ゲームの概要

- **ジャンル**: 取り調べ推理アドベンチャー
- **目的**: 4人の容疑者の中に紛れた **「人格AI（真犯人）」を1人見つけ出す**
- **期間**: **7日間**。最終日（7日目）に AI だと思う人物を「AI確定」して判定する
- **プレイの流れ**: 毎日、容疑者に取り調べをしてポイントを稼ぎ、ポイントで資料（プロフィール）を解禁して手がかりを集める

### 登場人物

| ID | 名前 | 年齢 | 職業 | 備考 |
|---|---|---|---|---|
| A | ココア | 17歳 | 高校生 | **現在の設定では AI（真犯人）** |
| B | メリ | 22 | ジャーナリスト | |
| C | カネル | 26歳 | （職業欄に「12月24日(クリスマス)」と入っている。データの入力ミスの可能性あり） | |
| D | レイジ | 24歳 | フリーター | |
| — | 補助ちゃん | — | — | スマホで話せるサポート役 |

> AI がだれかは `InGame.prefab` の GameManager の `All Characters` にある `Is AI` で設定します。

## 2. 画面の流れ

```
Title（タイトル）
  └─ スタート → InGame（本編）
        ├─ 7日目に AI を正しく判定 → ClearScene（クリア）
        └─ それ以外                → GameOverScene（ゲームオーバー）
              └─ どちらも → Title に戻る
```

- 起動時に **Manager シーン**（BGM・効果音の AudioManager）が自動で追加読み込みされます。
- Result シーンはビルド設定で無効になっていて、現在は使っていません（リザルトは InGame の中の画面で表示）。

### InGame の中の画面

| 画面 | 内容 |
|---|---|
| モニター画面 | 4つの部屋（A〜D）を選ぶ。プロフィール・リセット・1日終了・ログ・**スマホ**のボタンがある |
| 取調室 | 選んだ容疑者にアクションを行う。セリフは画面下の会話枠に表示 |
| プロフィール（資料） | ポイントで容疑者の基礎情報・過去情報を解禁して読む |
| 聞き取りパネル | 「聞き取り」で、だれについて聞くかを選ぶ |
| ログ | これまでのセリフを読み返す |
| リザルト | 1日の終わりに、その日の取り調べ内容と獲得ポイントを表示 |
| スマホ会話画面 | 補助ちゃんと話す |
| ロード画面 | 日付が変わるときに「N日目 / Now Loading...」を表示 |

## 3. ゲームのルール

### 1日の流れ
1. モニター画面で部屋を選び、取調室でアクションを行う
2. **1日に行動できるのは4回まで**。**同じ人には1日1回まで**
3. 「1日終了」ボタン → 確認 → リザルト画面 → 「次の日へ」で翌日（ロード画面が入る）

### 取調室のアクション

| アクション | 効果 |
|---|---|
| 拷問 / 対話 / 交渉 | その日の「正解の行動」だと **ポイント獲得＋好感度+1**。外れると **ポイント-5**（0未満にはならない）。その日の「NG行動」だった場合は **好感度-1** |
| 聞き取り | 他の人について話を聞く。**正解判定なしで +10ポイント** |
| 解放 | その人を解放する（行動1回を使う）。**以後その人は取り調べできない**。AI を解放してしまうと **ゲームオーバー確定** |
| AI確定 | **最終日（7日目）だけ**表示。行動回数を使い切っていても押せる（行動回数は使わない）。押すとリザルト → 判定へ |

- 正解時のポイントは現在 **200**（シーン側の設定値。prefab 側は 2000000 になっているので、意図した値か要確認）。
- 「正解」は **その日の正解行動を選び、かつセリフ設定の1番目の条件に当てはまったとき**です（下の「既知の問題」参照）。

### セリフの出し分け
各キャラ・各アクションごとに「優先度順のセリフリスト」があり、上から順に条件をチェックして最初に当てはまったセリフが出ます。

| 条件 | 内容 |
|---|---|
| TargetAffection | 本人の好感度が指定値以上 |
| OtherAffection | 指定した他キャラの好感度が指定値以上 |
| TotalActions | このキャラにこのアクションをした通算回数が指定値以上 |
| Unconditional | 条件なし（デフォルト） |

### プロフィール（資料）の解禁
- ポイントを消費して解禁します。解禁状態はキャラごとに別です。
- 基礎情報: ココア 20pt、それ以外 30pt
- 過去情報: 50pt / 70pt / 30pt（`PAST_1` 〜 `PAST_3`）
- **画面の置き場所の都合で、過去情報は3番目の枠（PAST_3）だけ表示**しています（意図した仕様）。

### 今日をやり直す（リセット）
その日の朝の状態に戻します。戻るもの: ポイント、行動回数、取り調べ済みの記録、好感度、プロフィールの解禁、**解放**、アクションの通算回数、スマホの会話回数。

### スマホ（補助ちゃんとの会話）
- モニター画面のスマホを押すと補助ちゃんの会話画面が開きます。
- **1日に聞ける回数 ＝ その日に用意したセリフの数**。使い切った後に押すと「**今日はもう連絡ができない**」と表示されます。
- 翌日・リセットで回数は戻ります。

### 勝ち負け
- **クリア**: 7日目に AI（現在はココア）を「AI確定」し、かつ AI を一度も解放していない
- **ゲームオーバー**: 人間を AI と判定した / AI を解放した / 7日目に判定しなかった

### 各日の正解行動（ネタバレ注意）

| 日 | A ココア | B メリ | C カネル | D レイジ |
|---|---|---|---|---|
| 1 | 対話 | 対話 | 対話 | 交渉 |
| 2 | 対話 | 対話 | 対話 | 対話 |
| 3〜7 | 拷問 | 対話 | 対話 | 対話 |

## 4. データの編集方法

| 何を | どこで |
|---|---|
| 取り調べのセリフ・正解行動 | `Assets/TechC/SchoolGameJam2026/Data/Day1〜7_Scenario.asset`（Inspector） |
| 容疑者のプロフィール | `Data/*_ProfileData.asset` |
| 補助ちゃんのセリフ | `InGame.prefab` の `Canvas/SmartphoneTalkPanel` → DialogueClickable（「＋回数を追加」で1日に聞ける回数が増える。改行ごとに1ページ） |
| ポイント・行動回数などの数値 | `InGame.prefab` の GameManager（InterrogationManager）。※シーン側で上書きされている値もある |
| ロード画面の時間・見た目 | `Canvas/DayTransitionPanel`（DayTransitionUI） |
| 「今日はもう連絡ができない」の表示時間 | MonitorPanel の MonitorUI → Notice Duration |

### セリフの書き方（取調室）
- `|` でページを区切る（クリックで次のページ）
- ページの先頭に `[SYS]` を付けると話者名なしの地の文になる
- `[IMG:OFF]` で立ち絵を消す（`[IMG:ON]` で戻す）

### Excel（CSV）でのセリフ管理について
`Tools > シナリオCSVインポーター` で CSV から読み込めますが、**現在は読み込み先（`Assets/Resources/Scenarios`）とゲームが使っているデータ（`Data/`）が別**です。Excel のセリフを入れる段階で、どちらかに統一する必要があります（下の「残っている作業」参照）。

## 5. 進行状況

### できているもの
- 7日間のゲーム進行、1日4回の行動制限、リザルト、翌日への切り替え
- 取調室の全アクション（拷問・対話・交渉・聞き取り・解放・AI確定）とクリア／ゲームオーバー判定
- セリフのページ送り・文字送り・ログ
- プロフィールの解禁
- 今日をやり直す（リセット）
- 日付切り替えのロード画面風演出
- スマホで補助ちゃんと会話（1日の回数制限つき）
- BGM（タイトル・本編）
- 自動テスト（14本、すべて成功）

### 仮のまま・作りかけのもの
- 補助ちゃんのセリフ（各日に仮の文が1件ずつ）
- スマホ会話画面・ロード画面・お知らせ表示の **見た目（位置・色・大きさ）は仮**。デザイナーさんの調整待ち
- 設定ボタン（`Setting_Button`）: 押しても何も起きない。Canvas の外にあり表示されていない可能性あり
- オプション（音量設定）: `Work_MIYOSI` の作業用シーンにだけあり、本番シーンに未配置
- ボタンの効果音: 仕組みはあるが、本番シーンのボタンに `ButtonSoundTrigger` が付いていない
- 夜フェーズ: 行動を使い切ると通知が出るだけで、受け取る処理がない
- クリア／ゲームオーバー画面: 文字がない（画像だけで作る予定なら問題なし）

### 既知の問題・要確認
| 内容 | 影響 |
|---|---|
| Excel 取り込み先と実際に使うデータが別 | Excel を編集してもゲームに反映されない |
| CSV の優先度（Priority）を飛ばすとエラー | 例: 1 と 3 だけ書くと取り調べ中に止まる |
| CSV のセル内改行・`"` に未対応 | セリフ内の改行は `\n` と書く必要がある |
| 正解判定がセリフリストの並び順に依存 | セリフの順番を入れ替えると正解判定が変わる |
| 正解ポイントが prefab 2000000 / シーン 200 | 意図した値か確認 |
| シーンで `Header`（日数・ポイント・行動回数の表示）が非表示 | プレイ中に日数などが見えていない可能性 |
| カネルの職業欄に誕生日が入っている | データの入力ミス？ |
| GameManager の DontDestroyOnLoad が効いていない（子オブジェクトのため） | 実害はないがコンソールに警告が出る |

## 8. 作業するときの注意

- コミットメッセージは `fix:` `feat:` `refactoring:` `chore:` `test:` の接頭語＋日本語で内容を書く。
